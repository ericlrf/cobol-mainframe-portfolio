# RDz / IDz e estação de desenvolvimento

Fluxo conceitual:

1. editar COBOL/JCL/copybooks no IDE;
2. validar sintaxe e dependências;
3. submeter build no z/OS;
4. revisar spool;
5. depurar em ambiente de teste;
6. promover elemento pelo Endevor;
7. executar testes e evidências.

O repositório Git representa o lado distribuído do fluxo; Endevor representa a governança de artefatos mainframe no exemplo.
