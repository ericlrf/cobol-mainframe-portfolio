# Xpediter, Abend-Aid e File-Aid

## Xpediter
Use em ambiente autorizado para breakpoint, inspeção de dados e fluxo de execução.

## Abend-Aid
Use para transformar abend/dump em contexto acionável: programa, offset, statement, dados e cadeia de chamadas.

## File-Aid
Use para examinar datasets de teste, layouts e registros. Alterações devem respeitar governança e rastreabilidade.
