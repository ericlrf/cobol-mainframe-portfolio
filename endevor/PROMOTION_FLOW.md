# Endevor — fluxo de promoção

Ambientes conceituais:

`DEV -> QA -> HML -> PRD`

Tipos de elemento:

- COBOL source
- COPYBOOK
- BMS map
- JCL
- DB2 DDL/package metadata

Controles esperados:

1. mudança associada a demanda;
2. compile/build reprodutível;
3. evidência de teste;
4. package/element promotion;
5. segregação entre desenvolvimento e produção;
6. rollback/backout planejado.

No ambiente real, processors, stages e regras seguem a configuração da organização.
